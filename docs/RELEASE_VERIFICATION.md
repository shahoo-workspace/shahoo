# بررسی نسخه پس از ادغام PR #11

این صفحه برنامهٔ آزمون نسخه است. وضعیت فعلی هر مورد در [گزارش آزمون](../TEST_REPORT.md) و ایشوی مربوط به آن ثبت می‌شود.

## آزمون‌های خودکار

| بررسی | محیط و معیار قبولی |
| --- | --- |
| `npm run test:project` | آزمون ارتقا، نمونهٔ سفارش و ارسال را در PGlite از طرح `0016` به `0019` می‌رساند. رکورد قدیمی، داده‌های JSONB و محدودیت یکتایی پس از ارتقا و اجرای دوباره بررسی می‌شوند. |
| `node scripts/test-postgres-smoke.mjs` | job PostgreSQL در GitHub Actions، پس از اعمال مهاجرت‌ها. تاریخچهٔ ثبت‌شده باید دقیقاً با فایل‌های نسخه مطابق باشد و هر دو ستون snapshot از نوع JSONB باشند. اسکریپت فقط دیتابیس محلی و موقت `shahoo_test` را می‌پذیرد. |
| بازیابی Windows و Linux | CI، روی منابع موقت. تاریخچهٔ مهاجرت، سلامت برنامه و دادهٔ بازیابی‌شده باید بعد از بازیابی قابل بررسی باشند. |

## آزمون‌های عملیاتی

| بررسی | آنچه باید ثبت شود |
| --- | --- |
| خرید در Preview | شناسهٔ استقرار، نسخهٔ کد و اتصال تأییدشده به Staging. پس از فعال‌کردن یک روش ارسال آزمایشی مجاز، ثبت یک سفارش پرداخت‌نشده و بازشدن رسید را بررسی کنید. |
| مدیریت و رسانه در Preview | با حساب آزمایشی مجاز وارد شوید. یک تصویر ساختگی را بارگذاری و از مسیر برنامه دریافت کنید. حذف همان فایل و رد دسترسی مستقیم ناشناس به باکت را بررسی کنید. |
| بازیابی روی میزبان هدف | نسخهٔ سیستم و Node، شناسهٔ پشتیبان، زمان بازیابی و شواهد سلامت برنامه، worker و دسترسی به رسانه را ثبت کنید. |
